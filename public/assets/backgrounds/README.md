# 像素RPG游戏 - 背景图片说明

## 背景图片位置

所有背景图片位于: `public/assets/backgrounds/[theme]/`

## 三种主题

### 1. 太空主题 (space)
- **位置**: `public/assets/backgrounds/space/`
- **特点**: 深蓝色太空，闪烁星星，漂浮小行星

### 2. 森林主题 (forest)
- **位置**: `public/assets/backgrounds/forest/`
- **特点**: 淡蓝色天空，白云飘浮，翠绿草地和树木

### 3. 地牢主题 (dungeon)
- **位置**: `public/assets/backgrounds/dungeon/`
- **特点**: 暗色调，废墟和岩石

## 每种主题包含的图片

每个主题文件夹包含4张PNG格式的背景图片：

1. **sky.png** - 天空层
   - 包含: 天空背景、云朵/星星
   - 视差速度: 0.1 (最慢)
   
2. **mountains.png** - 远景山脉层
   - 包含: 连绵的山脉/丘陵
   - 视差速度: 0.3 (中等)
   
3. **foreground.png** - 前景层
   - 包含: 草地、树木/装饰物
   - 视差速度: 0.7 (最快)
   
4. **background.png** - 完整背景
   - 包含: 所有图层合成的完整背景
   - 用于不需要视差效果的场景

## 视差滚动效果

游戏实现了三层视差滚动效果：
- **天空层**: 移动最慢，营造深度感
- **山脉层**: 中等速度，增加层次感
- **前景层**: 与角色同速，提供沉浸感

## 自定义图片

如果你想替换背景图片：

1. 准备PNG格式的图片
2. 确保图片分辨率为 **1920×720** 像素
3. 确保图片左右边缘无缝拼接
4. 放入对应主题的文件夹
5. 图片会自动加载

### 命名规范
- `sky.png` - 天空背景
- `mountains.png` - 远景山脉
- `foreground.png` - 前景草地/树木

## 技术细节

- **分辨率**: 1920×720 像素
- **格式**: PNG (支持透明通道)
- **风格**: 8-bit像素艺术
- **颜色**: 低饱和度，柔和色调
- **特点**: 无缝循环，适配横版卷轴游戏

## 图片生成脚本

如果需要重新生成程序化背景图片：

```bash
node generate-backgrounds.js  # 生成BMP背景
node convert-to-png.js       # 转换为PNG格式
```

## 提示

- 图片已优化为像素风格渲染
- 保持 `image-rendering: pixelated` CSS属性以获得最佳效果
- 前景层应该包含透明区域以便看到后面的图层
