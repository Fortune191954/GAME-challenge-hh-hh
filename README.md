# 像素冒险 RPG

一个用 HTML5 Canvas + 原生 JavaScript 写的横版像素闯关小游戏，零构建、零框架、前端零依赖。
线上试玩：https://fortune191954.github.io/GAME-challenge-hh-hh/

## 玩法

- **三张主题地图**：🌲 森林 → 🌌 太空 → 🏰 地牢，走到地图尽头过关
- **战斗**：普攻伤害 = 基础 15 + 武器攻击；**技能**消耗 30 体力发射贯穿弹（40 伤害，可打穿一列敌人）
- **体力 (SP)**：上限 100，约 3.6 点/秒自动恢复
- **装备**：武器加攻击、护甲减伤（每点防御减 5%，上限 80%），背包里点一下即装备
- **经济**：击杀掉金币，商店买药水/武器/护甲
- **幸运方块**：每击杀 3 只怪刷 1 个（上限 5），50 金币开一次，可能爆金币也可能刷出敌人

操作：`A`/`D` 移动（手机端用虚拟摇杆），「攻击」「技能」「道具」三个按钮。

## 快速开始

```bash
git clone https://github.com/Fortune191954/GAME-challenge-hh-hh.git
cd GAME-challenge-hh-hh
```

**方式一：直接玩**（纯前端，无依赖）
双击 `index.html`，或用任意静态服务器指向仓库根目录。

**方式二：带后端**
```bash
npm install
node server.js      # http://localhost:3001
```

后端只有注册/登录/存档/排行榜四个接口，前端页面**尚未接入**（没有登录界面），
数据存在内存里，重启即丢。

## 测试

```bash
npm test
```

`test-game.js` 零依赖，用 Node 内置 `vm` 搭一套最小 DOM/Canvas 桩件，真实驱动游戏循环，
覆盖初始化、刷怪与剔除线、攻击击杀结算、装备加成与减伤、技能与体力、商店、道具、
幸运方块全流程、半圆快速背包、DPR 缩放、摇杆、关卡完成、暂停恢复、退出兜底。
全部通过时退出码为 0，可直接接 CI。

## 项目结构

游戏代码**只有一份**，在仓库根目录 —— GitHub Pages 部署的和本地跑的是同一份。

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构与所有 UI 容器 |
| `game.js` | 全部游戏逻辑（单文件） |
| `style.css` | 像素风格样式，含移动端适配 |
| `assets/` | 背景图与幸运方块图片 |
| `image/` | 原始素材（玩家/怪物/武器大图，当前未接入代码） |
| `server.js` | 可选的 Express 后端 |
| `test-game.js` | 冒烟测试 |
| `经验.md` | 踩坑与修复记录（改动前建议先翻这里） |
| `QUICKSTART.md` | 面向新手的启动与开发说明 |

## 开发约定

1. 改 `game.js` 后先跑 `npm test`
2. 平衡数值集中在 `game.js` 顶部的常量区，不要散落在逻辑里
3. 静态资源一律用**相对路径**（Pages 部署在子目录，`/assets/...` 会 404）
4. 新增问题/改动在 `经验.md` 里补一条记录
5. 渲染用 emoji + `fillText`，素材大图尚未接入 —— 想换真图需要改 `render()`
